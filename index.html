How API move fetching works

After each legal move, the app reads the current FEN and makes two fixed opening-data requests: Masters database, plus Lichess 2500+ rapid/classical/correspondence.

On your turn, a database move is usable when its qualification games clear the selected depth and your color score is ≥50% in Masters or Lichess. If both sources are ≥50%, games combine; if only one is ≥50%, the larger source game count is used. Master and Lichess scores stay separate on every row.

If your move fails the 500+ game / 50%+ score rule, it is rejected, counted as a mistake, and automatically undone. If no database move qualifies for your color, the opening is considered learned. On the enemy turn, the app plays the most popular uncompleted API database response, ignoring game count and score.

Stats will appear after the first lookup.

Welcome to LineForge

How LineForge works

You control your assigned side; the enemy replies from database games. LineForge is an opening-line trainer: your move list is filtered by Masters/Lichess depth and color score. When the database rule runs out, the opening is considered learned.

1. Board control

Choose your assigned side in setup. On your turn, click or drag a legal move, or click a candidate move. The enemy side replies automatically from the database pool.

2. Player setup

“Assign your name to White/Black/Random” chooses your training side, PGN headers, and default board orientation. The opposite side is the enemy database side.

3. API move fetching

After every move, the app sends the current FEN to the Lichess Opening Explorer API twice: Masters database, and Lichess 2500+ rapid/classical/correspondence games.

4. Sources

The sources are hardcoded: Masters database for OTB master games, plus Lichess 2500+ rated games at rapid, classical, and correspondence speeds.

5. Depth and score rule

Your database moves must clear the selected qualification-games threshold with your color score ≥50% in Masters or Lichess. If both databases are positive, game counts combine; if only one is positive, the higher game count is used. The depth slider values are exactly 100k, 50k, 10k, 5k, 1k, 500.

6. Move ordering

The default mode sorts qualifying Masters moves first by your color score. Lichess-only moves appear only if Masters has no qualifier. You can switch to a combined list that keeps Masters and Lichess scores separate.

7. Completion

When your side has no qualifying database move, or the enemy has no uncompleted database response, the app congratulates you and completes the line. If you connect OpenRouter, Forgey explains why your corrected move beat your rejected attempts.

8. API access and tokens

If the explorer returns 401, generate a Lichess OAuth token. On GitHub Pages, paste it into this browser's token field. With the included Node server, use LICHESS_TOKEN / local-secrets.json and the proxy enables automatically.

Privacy/security: API keys and progress are saved in this browser with localStorage. For public/shared devices, clear keys when done. For real deployment, use the included /api/explorer proxy pattern so tokens stay server-side.
